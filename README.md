# Mini Compiler

A basic Mini Compiler built in Python.

## Features
- Lexical Analysis (Lexer)
- Syntax Analysis (Parser)
- Semantic Analysis
- Intermediate Code Generation
- Code Optimization
- Final Code Generation

## Project Files

- lexer.py
- parser.py
- semantic.py
- intermediate.py
- optimizer.py
- codegen.py
- main.py

## How to Run

```bash
python main.py
